# FloatTodo｜Windows 悬浮待办（MVP v0.1.1）

一个无账号、无云端的 Windows 桌面悬浮球待办应用，使用 **C# / WPF / SQLite** 开发。

> 注意：这是可交给 Windows 开发环境编译的**源码项目**，不是已测试的 Windows 安装包。当前生成环境为 Linux，没有 Windows 和 .NET SDK，无法完成 Windows 实机编译/交互测试。项目内提供 Windows GitHub Actions 构建配置。

## 已实现

- 64 DIP 圆形置顶悬浮球，可鼠标左键按住拖动。
- 松开时距左右屏幕边缘 ≤30 物理像素，吸附至边缘；移开鼠标后半隐藏，露出 40%。
- 鼠标移入时恢复，自动打开悬浮待办面板；离开悬浮球和面板约 350ms 后收起。
- 待办新增、编辑、删除、完成、取消完成；完成与待办分栏。
- **拖拽排序**：在“待办事项”和“已完成”列表中，按住每行左侧 ⠿ 手柄拖到其他任务的上半/下半部分，可插入目标之前/之后；两个列表独立排序，顺序会永久保存。拖动至滚动区域边缘可自动滚动。
- 面板避开当前显示器边界，支持负坐标的多屏布局。
- 系统托盘：显示、打开待办、设置、退出；悬浮球右键同样可操作。
- 可在设置中修改吸边阈值、露出比例、收起延迟。
- SQLite 本地持久化；位置和吸附方向在重启后恢复。
- 没有管理员权限请求、账号、网络通信、遥测或后台录制行为。

## 快速运行

**环境要求：** Windows 10/11；[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)（开发/自行编译时）。

打开 PowerShell，进入此文件夹，然后执行：

```powershell
dotnet restore
dotnet run
```

或者使用 Visual Studio（包含 .NET 桌面开发工作负载）打开 `FloatTodo.csproj`，按 F5 运行。

**生成独立 EXE：** 在 Windows PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Build-Release.ps1
```

生成目录：`publish\FloatTodo.exe`。发布使用 `--self-contained`；首次启动可能需要等待打包的 SQLite 原生库释放。若使用公司电脑，杀毒软件可能会阻止尚未签名的自编译程序。无需管理员权限。

**GitHub 构建：** 将项目推到 GitHub 后，Actions 的 `Windows build` 工作流会使用 Windows 运行器构建并上传 Windows x64 可执行文件压缩包。

## 使用方法

1. 启动后屏幕右上方附近出现蓝色悬浮球。
2. 左键拖动，靠近显示器左右边缘后松开；鼠标移开会半隐藏。
3. 鼠标进入悬浮球自动展开待办；文本框输入任务并按 Enter 或“+ 新建”。
4. **排序**：按住任务左侧的 ⠿ 手柄拖动，放到目标任务的**上半部**表示排在它之前，**下半部**表示排在它之后；待办与已完成只允许各自在本组内排序。
5. 勾选完成、取消勾选恢复；“编辑”修改文字，“×”直接删除（删除不会弹确认）。
6. 右键悬浮球或右键系统托盘图标打开菜单；若悬浮球隐藏，可从托盘恢复。

数据位于 `%LOCALAPPDATA%\FloatTodo\`：

- `todos.db`：SQLite 待办库。任务原始创建/完成时间为 UTC，另外保存 `SortOrder` 排序字段；当前 UI 还不展示时间。
- `settings.json`：悬浮球位置、吸附方向与交互参数。

**升级 v0.1 → v0.1.1：** 本次同时包含 `ImplicitUsings=disable` 的 CS0104 命名冲突修复。新程序首次启动会自动为旧版数据库增加 `SortOrder` 列，按照旧版顺序初始化任务排序，**不会删除待办或已完成记录**。之后新增任务在待办列表最前面；勾选完成或恢复会移动到对应目标列表最前面。

**重要：数据库升级是单向的。** 升级前建议先退出旧版本，复制 `%LOCALAPPDATA%\FloatTodo\todos.db` 作为备份。两个版本共用此数据目录，不要同时运行，也不要复制覆盖或删除数据库。

## 手工验收清单（必须在 Windows 上执行）

- [ ] 100% 和 150% DPI 下圆形悬浮球能拖动；拖到左右边缘露出约 40%。
- [ ] 鼠标移入能恢复并展开待办，快速移入面板不会意外收起。
- [ ] 新建、编辑、完成、取消完成、删除后，重新启动数据仍在。
- [ ] 待办列表的第一项拖到最后、最后项拖到最前，视觉反馈与最终顺序正确。
- [ ] 已完成列表也可独立排序；跨列表拖拽不改变任务完成状态。
- [ ] 排序后退出/重启，顺序不变；旧版本数据库升级后旧任务完整保留。
- [ ] 新增/勾选完成/取消完成/编辑/删除之后，其他任务已排列好的顺序不变。
- [ ] 长列表拖到滚动区域上下边缘能滚动；拖拽时面板不会提前自动隐藏。
- [ ] 右键菜单和托盘均可隐藏、恢复、退出；没有孤儿托盘图标。
- [ ] 拔掉/接回第二显示器（包括副屏放在主屏左边）并重启，球出现在可见屏幕内。
- [ ] 两台显示器缩放不同（100%/150%）时拖动和靠边吸附正常。
- [ ] Windows 任务栏分别放在底部、左侧和自动隐藏状态时面板没有越界。
- [ ] 睡眠唤醒、全屏应用切换后，置顶及交互符合预期。

## 后续开发计划

1. **自定义皮肤**：基于已经分离出的 `Views/BallVisual.xaml` 进一步实现皮肤渲染器。第一步支持 PNG/静态透明图片，再支持精灵帧和简单动画。非圆形角色需处理透明区域命中测试与吸附宽度。
2. **定时任务**：为任务增加 `DueAtUtc`、时区和重复规则，事件处理分离为 `ReminderService`。提醒要处理睡眠恢复、错过的提醒和免打扰。
3. **时间日志**：新增事件表（开始、停止、备注、时间戳）。先支持用户手动开始/停止与填写记录，不要默认监控其他软件或键盘行为。
4. **喝水/久坐提醒**：复用统一定时调度器，支持工作日、间隔、自定义提醒频率、暂停与防打扰。
5. **数据库升级**：已对 `SortOrder` 实现兼容旧版的数据迁移；后续扩展表时逐步引入版本号迁移。

## 已知边界

- 仅面向 Windows，不支持独占全屏游戏与 UAC 安全桌面上的强制置顶。
- 当前没有主动定时提醒、系统开机启动、云同步、日志、皮肤切换；这些留到后续版本。
- 首版使用托盘图标并依赖鼠标操作；键盘无障碍、屏幕阅读器与触控手势尚需优化。
- Windows 在热插拔显示器、系统 DPI 动态变化后可能重新定位窗口，需要 Windows 实机测试确认边缘细节。
- 此项目尚未在真实 Windows 机器上完成编译及运行验收；如有构建错误，优先参考仓库 Windows CI 结果。
