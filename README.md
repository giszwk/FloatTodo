# FloatTodo v0.2.0｜Windows 悬浮待办与轻提醒

基于已经实测可用的 **v0.1.1（拖拽排序版）** 扩展，使用 C# / WPF / SQLite，Windows 10/11，.NET 10 SDK。

> **交付状态：源码候选版。** 在当前 Linux 工作环境完成了 XAML/事件静态检查、SQLite v0.1/v0.1.1 升级模拟及插入排序逻辑模拟；**尚未在 Windows 编译或操作验证**。可通过本仓库的 Windows GitHub Actions workflow 或在本机执行 `dotnet build` 验证。

## 新增内容

### 1. 任务提醒

- 普通待办：仍可在悬停面板文本框直接输入并回车新增。
- 新建计划：点击 **「计划」**（或悬浮球右键/托盘菜单的“新建计划任务”），选择名称、日期、时间、重复方式，决定是否到点提醒。
- 到点：悬浮球旁显示 10 秒提醒卡片，提供「完成任务」「10 分钟后」和右上角关闭。
- 关闭提醒不等于完成。任务仍在待办中；提醒默认只弹一次，点“10 分钟后”会再次弹出。
- 多个任务在关闭/休眠期间同时到期，统一汇总成一张提醒；其余到期任务仍保持未完成状态，请在待办面板查看。

### 2. 循环任务

- 支持**每天 / 每周 / 每月**，以及**不重复**。
- 创建循环任务时会立刻在待办列表生成首次任务，其计划日期显示在标题下方。
- 此后每次到达计划时间会生成一个独立的待办实例；**完成/删除某次任务不会影响未来的循环生成**。
- 点击悬停面板右下角 **「循环管理」**，可停止未来生成；已生成实例及历史已完成记录不会被清除。
- 关机/休眠跨过多个周期时，重新打开后**每个循环规则仅补建最近一个错过的实例**，避免历史任务堆积。
- 每月指定 29/30/31 日，如果某月没有该日期，则自动使用该月最后一天；下一个月份仍按原始日数安排。
- 当前版本**不支持直接编辑循环规则**，可停止旧规则并创建新规则。编辑任务名称仅作用于当前实例。

### 3. 健康提醒

- 在右键菜单「设置」中调整：**喝水提醒（默认每 60 分钟）**、**久坐提醒（默认累计活跃 50 分钟）**、提醒音效、免打扰时间、全屏抑制。
- 喝水按应用运行中的时间计时；久坐按键鼠活动粗略估计，连续空闲 5 分钟视为离开电脑，清除累计活跃时间。**它不等价于真实姿态检测**。
- 默认 22:00–09:00 免打扰，声音默认关闭；全屏前台应用时默认抑制提醒，可在设置关闭。
- 健康提醒不会自动添加为任务、不会记入已完成任务列表。关闭/重启应用会重新开始健康计时。
- 对健康提醒也有「10 分钟后」和「我喝过了／我已活动」操作。

### 4. 改进拖拽插入位置

- 按住左侧 **⠿** 手柄拖动。
- 插入位置通过 **蓝色横线** 表示，不再让整个 B 任务边框高亮。
- 比如 A、B、C 排列：拖动 A 到 **B 下半部**，或 **B 和 C 的间隙**，或 **C 上半部**，均对应横线出现于 B 与 C 之间，放下后顺序为 B、A、C。
- 也支持列表最后的尾部空白区域、顶部、长列表滚动；待办与已完成仍分别排序，不允许跨组拖动。
- 调整的顺序保存 SQLite，重启不丢失。

### 5. 旧版本修复与兼容

- 继续保留 `<ImplicitUsings>disable</ImplicitUsings>`，避免 WPF 与 WinForms 类名冲突（CS0104）。
- 保留 v0.1.1 的悬浮球拖动、半隐藏、托盘、位置保存等能力。
- 首次启动自动为 v0.1/v0.1.1 数据库**添加列和循环规则表**，**不删除原任务、已完成记录或排序**。
- 所有任务、设置只保存在 `%LOCALAPPDATA%\FloatTodo`，无需云账号或管理员权限。

## Windows 本地升级与运行

**强烈建议先退出托盘旧版，再备份数据。**

```powershell
Copy-Item "$env:LOCALAPPDATA\FloatTodo\todos.db" "$env:LOCALAPPDATA\FloatTodo\todos.before-v0.2.db"
```

如果你已经把项目纳入 Git，建议先在现有 v0.1.1 仓库执行：

```powershell
git switch main
git switch -c feature/v0.2-reminders
```

把本源码包 `FloatTodo` 目录的内容复制进 Git 工作目录（**不要覆盖 `.git` 目录，也不要复制本机数据库**），然后：

```powershell
dotnet restore
dotnet build
dotnet run
```

完成 Windows 交互验收后才合并或打标签：

```powershell
git add .
git commit -m "feat: reminders recurring tasks health prompts and drop insertion line"
git switch main
git merge feature/v0.2-reminders
git tag v0.2.0
```

如果尚未使用 Git，直接解压到**新文件夹**并从 `FloatTodo.csproj` 所在目录运行上面的 dotnet 命令。两个版本共用数据库，不能同时运行。

发布独立 EXE：`powershell -ExecutionPolicy Bypass -File .\Build-Release.ps1`。

## Windows 端重点验收清单

- [ ] `dotnet restore`, `dotnet build`, `dotnet run` 均成功；无 CS0104。
- [ ] v0.1.1 的任务内容、已完成记录、拖拽顺序均保留。
- [ ] A 拖到 B 下半部、B/C 间隙、C 上半部，均显示 B/C 间的横线；松开后新顺序正确，重启后保持。
- [ ] 待办与已完成各自能调整顺序，不允许跨组拖动。
- [ ] 新建 1–2 分钟后的单次提醒，弹出卡片；关闭、完成、10 分钟后操作正确。
- [ ] 新建每日/每周/每月规则并在「循环管理」停止；现有任务仍在。
- [ ] 检查免打扰时段、全屏、不播放声音等选项。
- [ ] 为测试健康提醒，将间隔设置成允许的最短 10 分钟；健康提醒不加入任务列表。
- [ ] 吸附屏幕左右两边时，气泡朝屏幕可见区域展开；在多显示器、125/150% 缩放下测试。
- [ ] 休眠/恢复、多条任务过期后只有合并提示，没有刷屏。
- [ ] 关闭/重启后设置、计划和待办记录仍保存。

## 已知限制

- **尚未在 Windows 本机编译和交互测试**，请先在新目录以 `dotnet build` 验证。
- 调度只在 **FloatTodo 程序运行时**执行；不创建 Windows 计划任务，退出应用后不会弹提醒，重开后补提示。
- 任务计划使用**当前 Windows 本地日期和时间**，跨时区旅行、夏令时切换场景尚需实机验证。
- 由于 Windows 全屏/键鼠空闲的判断只是一种启发式方法，某些全屏应用或长时间不操作鼠标的阅读场景会偏差。
- 当前没有计划编辑器（仅创建／停止循环）；没有自定义皮肤、时间日志、云同步。
- 当前气泡关闭时间约 10 秒；不含动画和通知中心。

## 数据模型概览

- 旧 `Tasks` 表：原数据保留；增添 `DueLocal`、`ReminderEnabled`、`SeriesId`、`AlertedUtc`、`SnoozedUntilLocal`。
- 新 `RecurringSchedules` 表：保存模板、下次生成时间、是否启用。
- `settings.json`：保留悬浮球设置并新增健康提醒参数。
- 计划时间使用本地 `yyyy-MM-ddTHH:mm:ss`；系统内部保存历史创建、完成和提醒状态的 UTC 时间。

此版本基础设施也为后续 PNG 动漫角色皮肤与时间日志留出了扩展空间；二者目前尚未实现。
