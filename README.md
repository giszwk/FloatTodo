# FloatTodo v0.3.5 · 扒边专用眨眼 GIF

Windows 10/11 · C# / WPF · .NET 10 SDK · SQLite。源自 v0.3.3 GIF 皮肤版，**数据库结构不变**。

**v0.3.5 更新：** 内置用户提供的右侧探头 `peek.gif`（6 帧），半隐藏时默认第一帧静止，每 60–120 秒低频播放一次；靠左侧时沿竖直轴做左右镜像，靠右侧时使用原图。继续保留 v0.3.4 的 GIF 解码和空引用修复。

## 本版内容

- 使用用户提供的 `idle.gif`、`waiting.gif`、`review.gif` 和新的 `peek.gif`，作为**内置**黑猫 GIF 素材；已随源码打包，不必自行导入。
- 默认皮肤依然是蓝色悬浮球；到「设置 → 桌面皮肤」切换到「罗小黑 GIF」。
- **非隐藏状态**：绝大多数时间静止在 **idle 第 1 帧**（帧序号 0）。每隔 45–100 秒随机触发一次 `waiting`、`review`，按顺序交替；每次仅播放一遍，结束后恢复 idle 第 1 帧。
- **半隐藏状态**：默认显示新的 `peek.gif` 第一帧，每 60–120 秒触发一次眨眼（仅单次播放）。靠右使用原图、靠左按竖直轴镜像；素材保持完整尺寸，且罗小黑皮肤至少露出窗口宽度的 68%，确保猫脸、耳朵、爪子和扒边墙面都完整可见；鼠标移入时恢复完整皮肤。
- 原 v0.3.2 的按目标任务 ID 排序、蓝色插入线及托盘「显示/隐藏悬浮球」切换逻辑保留；皮肤只在设置中切换。
- 导入机制保留：展开 GIF、扒边 GIF、PNG 图集均可以在设置里自定义；自定义资源优先于内置 GIF，移除后恢复内置。
- 动画在两种状态之间切换时会停止当前播放，避免后台持续占资源。

## 运行和升级

1. 从托盘退出已有 FloatTodo；备份 `%LOCALAPPDATA%\FloatTodo\todos.db` 和 `settings.json`。
2. 如果正在使用 Git，切到新分支后复制本项目源码（不要覆盖 `.git`）；否则直接解压到新目录。
   **如果此前通过设置导入过自定义扒边 GIF**，该文件会优先于新内置 `peek.gif`；在「设置 → 皮肤」中清除自定义资源后才能看到内置素材。
3. 在 `FloatTodo.csproj` 所在目录运行：

```powershell
dotnet restore
dotnet build
dotnet run
```

4. 打开「设置」，选择「罗小黑 GIF」，保存。拖动到左/右屏幕边缘，移走鼠标观察半隐藏；移入时还原完整形态。
5. 如需发布免安装版，请运行 `powershell -ExecutionPolicy Bypass -File .\Build-Release.ps1`。

**注意**：需要随 EXE 保留 `Assets/Skins/LuoXiaoHei` 目录下 4 个 GIF。`dotnet publish` 会自动复制它们。即使生成单文件 EXE，外部 GIF 也应一并分发。

## 建议验收

- 切换到新皮肤后，展开状态是否只显示 `idle` 第一帧并保持不动；观察几分钟确认偶尔交替 `waiting/review`。
- 靠左和靠右时，半隐藏是否正确露出、鼠标悬停后正常展开；检查猫脸始终朝屏幕内部，左右方向正确。
- A/B/C/D 四条待办：A 插到 B 后、B/C 中间、列表顶部和末尾；蓝线与实际位置一致，重新运行后排序不变。
- 托盘菜单从「隐藏悬浮球」到「显示悬浮球」能往返切换，且没有切换皮肤菜单。
- 旧任务、定时提醒、循环任务、喝水/久坐提醒仍工作。
