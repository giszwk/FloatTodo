# FloatTodo v0.3.1 — Windows 悬浮待办 / 双皮肤

C# / WPF / SQLite，Windows 10/11，.NET 10 SDK。保留 v0.2 的全部功能：悬浮球吸边、待办拖拽插入线、定时和循环任务、喝水/久坐提醒、免打扰与托盘。

> **交付状态：源码测试候选版。** 已完成 XAML/事件关联静态检查、v0.2 逻辑回归脚本。当前环境不是 Windows，**没有完成 dotnet build 或 Windows 鼠标交互验证**。

## v0.3 新功能

| 皮肤 | 展开（非隐藏） | 靠边（隐藏） |
| --- | --- | --- |
| 默认蓝色悬浮球 | 完全保留原 64×64 外观和待办数字角标 | 保留可见比例的半隐藏逻辑 |
| 小黑猫（原创罗小黑风格） | 96×96 静态猫形；38–80 秒随机一次 Waiting / Review 交替短动作（约 1 秒） | 专用扒边猫脸与小爪；48–95 秒随机一次轻眨眼（约 0.36 秒） |

- 通过「设置 → 桌面皮肤」、悬浮球右键「切换皮肤」、系统托盘菜单切换。
- 皮肤选择保存于 `%LOCALAPPDATA%\FloatTodo\settings.json`，重启继续使用。
- 皮肤只影响外观，不改变拖动、吸边、待办、提醒、SQLite 数据。
- 展开动作位移非常小（约 1.5 像素），不做持续呼吸/跳跃动画。

## 可选：导入参考站点的动作图集

参考：https://codex-pets.net/#/pets/luoxiaohei2d

**本版本内置的是原创绘制的小黑猫，而不是直接复制参考站点角色素材。** 参考站点包含社区投稿的角色美术，授权不明确，本工程不分发这些帧。为了方便你在拥有使用权限时沿用 `Waiting` 和 `Review`，提供**本地 PNG 精灵图导入**：

1. 自行从参考页面取得有权使用的 `spritesheet.webp`。
2. 将其转换为 PNG，保留原尺寸和透明像素；例如安装 ImageMagick 后执行 `magick spritesheet.webp spritesheet.png`。
3. 设置 → 桌面皮肤 → 「导入原版风格图集（PNG）」 → 选择文件并保存。
4. 支持 1536×1872（8×9）或 1536×2288（8×11），格子为 192×208。非隐藏状态将显示原图中的 Idle（第 0 行）、Waiting（第 6 行）、Review（第 8 行）动画，每段最多播放 6 帧；**隐藏状态仍显示本项目自绘的扒边猫**。
5. 图集复制到 `%LOCALAPPDATA%\FloatTodo\skins\black-cat\spritesheet.png`；「移除导入图集」可回到自绘版本。

## 安装运行 / 升级

1. 系统托盘右键 **退出旧版 FloatTodo**，建议备份 `%LOCALAPPDATA%\FloatTodo\todos.db` 和 `settings.json`。
2. 建议解压新源码到新文件夹。若已经初始化 Git，请在自己的仓库创建 `feature/v0.3-skins` 分支，把新版源文件复制进去，**不要覆盖 `.git`**。
3. 在包含 `FloatTodo.csproj` 的目录打开 PowerShell：

```powershell
dotnet restore
dotnet build
dotnet run
```

4. 运行后在悬浮球右键菜单中选择「切换皮肤 → 小黑猫」，拖至左右边缘，移开鼠标观察扒边形态，再移入展开。
5. 可运行 `powershell -ExecutionPolicy Bypass -File .\Build-Release.ps1` 尝试生成 EXE。

**原有数据库无需手动迁移**：v0.3 不修改 v0.2 数据结构；`Skin` 设置缺失时默认使用原蓝色悬浮球。

### Windows 验收建议

- [ ] `dotnet build`、`dotnet run` 成功；没有 CS0104 冲突。
- [ ] 默认皮肤与 v0.2 一致，原待办和排序保持。
- [ ] 两种皮肤可以在设置、右键和系统托盘切换，重启后仍生效。
- [ ] 小黑猫靠左右边缘收起时露脸/小爪，移入能恢复完整站姿，待办面板仍可操作。
- [ ] 展开保持静态约 1 分钟后短暂呈现 Waiting、Review，隐藏阶段低频眨眼；不会一直动。
- [ ] 在左右边缘、不同 DPI / 多显示器和修改露出比例时检查效果。
- [ ] 可选 PNG 8×9/11 导入成功，重启加载、移除后回到内置皮肤。
- [ ] 到点提醒、循环任务、健康提醒及原拖拽插入线正常。

已知限制：WPF 透明窗口仍有矩形命中区域；目前非隐藏图集可读取 PNG 而不直接解码 WebP；动画间隔在每次展开/隐藏转换时重置；没有角色语音或物理模拟；原创造型仅参考黑猫观感，不保证与指定第三方原画像素级一致。
